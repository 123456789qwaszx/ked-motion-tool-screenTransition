# 쓰는 법

화면 전환 툴의 지금 모습(기반 시설 — `README.md`). 키 하나하나의 전체 표는 툴 안의 **단축키 (F1)** 창에 있다.

## 1. 실행

저장소 루트에서 `dotnet run --project src/Mt.App/Mt.App.csproj`. 빈 문서가 뜬다.
설정은 `%APPDATA%\ked-motion-tool\settings.json`(리눅스는 `~/.config/ked-motion-tool/`)에, 자동 저장은 문서 옆 `<이름>.autosave.motion-authoring.json`에 남는다.

## 2. 화면

```
┌ 툴바: 새로 · 열기… · 최근… · 저장 · 다른 이름으로… · 되돌리기 · 다시하기 · 설정… · 단축키 (F1)
├────────────────┬──────────────────────────────────┬────────────────────┐
│ 세트 목록       │ 뷰포트 (무대 1920×1080)            │ 인스펙터 탭         │
│ 층 (하이어아키) │ 타임 슬라이더 · 재생 · Auto Key     │  채널 박스          │
│ 모션 목록       ├──────────────────────────────────┤  세트              │
│                │ 그래프 / 도프 시트                 │  모션 · 연출        │
├────────────────┴──────────────────────────────────┴────────────────────┤
│ 문제 칸 (규칙 위반 · 경고 · 돕는 손)                                        │
└──────────────────────────────────────────────────────────────────────────┘
```

뷰포트에는 **세트 하나**가 선다 — 연 세트, 아니면 고른 연출의 세트, 아니면 고른 애니메이션의 세트. 층(하이어아키)은 그 세트의 오브젝트들이다.

## 3. 예시 보기

1. **열기…** → `examples/transitions/station/station.motion-authoring.json`.
2. 오른쪽 **연출** 탭에서 `station`을 고른다. **Alt+`** — 처음부터 재생: 층들이 차례로 들어와 화면을 덮고 머물다 걷힌다. **Alt+Q**는 재생/일시정지.
3. 재생 줄의 **무대만**을 켜면 무대 밖이 가려져 게임에서 보이는 그대로다.

## 4. 세트 짓기

1. 왼쪽 **새 세트**. 세트가 열리고(배치 모드) 뷰포트와 층이 그 세트만 보인다.
2. **층 표 가져오기…**(`layers.tsv` — 바탕색 + 층 그림들이 한 번에 선다) 또는 **그림 가져오기…**(PNG 여럿).
   층을 우클릭하면 오브젝트 더하기(그림 · 색 사각형) · 부모 바꾸기 · 앞뒤 순서 · 숨기기.
3. 뷰포트에서 오브젝트를 끌어 자리를 잡는다(Shift+드래그 배율 · Ctrl+드래그 회전) — 가만히 선 자세다. 오른쪽 **세트** 탭에서 이름 · 부모 · 자리 · 크기 · 색을 적는다.
4. **닫기**로 세트를 닫는다.

## 5. 움직이기

1. 세트를 연 채 **모션 추가** — 그 세트의 애니메이션이 생긴다. 오른쪽 **모션** 탭에서 이름 · 길이 · 종료 처리를 바꾼다.
2. 층에서 오브젝트를 고르고 하단의 **● Auto Key**를 켠다. 현재 시각을 옮기고 채널 박스의 값에 숫자 Enter — 채널 · 키가 한 번에 생긴다.
   뷰포트의 **W**(이동) · **E**(회전) · **R**(배율) 손잡이를 끌어도 같다. Auto Key가 꺼져 있으면 **키 없는 포즈**(주황)로 남고, **S**로 키를 놓거나 **Esc**로 버린다.
3. 층의 우클릭 메뉴: **화면 밖에서 들어온다 / 나간다**(지금 시각부터) · **여기서부터 차례로**(아래 형제들에 시차) · **제 차례 전까지 숨기기** · 움직임 밀기.
4. 그래프에서 커브를 다듬는다(MMB 드래그 이동 · Ctrl+1…6 탄젠트). 도프 시트에서 블록을 끌면 시간만 옮겨진다.
5. 화면이 다 덮이는 프레임에 이벤트 키 `covered`를 둔다 — 게임이 여기서 장면을 바꾼다.

종료 처리: **복원**(길이를 지나면 시작 상태) · **유지**(마지막 키가 남는다). 재생 기준: **상대값**(가만히 선 자세 + 키) · **절대값**(키 그대로).

## 6. 연출

**연출 추가** — 열어 둔 세트로 연출이 생긴다. 등장 · 머묾 · 퇴장에 애니메이션을 하나씩 고르고, 머묾의 길이(초)를 적는다. 고르면 수명 한 번이 돈다.

## 7. 저장

**다른 이름으로…** → `*.motion-authoring.json`(저작 원본). 산출물(게임이 읽는 파일)은 아직 없다 — T5에서 `transition/1`로 선다.
