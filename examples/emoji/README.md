# 이모지 예시

이모지 22개(말줄임점·쑥스럼 풍선은 반전 판 스킨이 따로 있다)를 실제 그림으로 세팅해 둔 문서다. 써 보면서 어디가 불편한지 찾으려고 만들었다.

- `emoji-examples.motion-authoring.json` — 앱에서 **열기…** 로 연다. 그림은 `art/`(문서 기준 상대 경로).
- 문서는 손으로 쓴 것이 아니라 편집기 명령으로 지은 것이다: `tests/Mt.Authoring.Tests/EmojiExamples.cs`.
  고쳤으면 `MT_WRITE_EXAMPLES=1 dotnet test tests/Mt.Authoring.Tests --filter EmojiExampleTests`로 다시 쓴다(테스트가 파일과 코드가 같은지 지킨다).
- 화면을 그림으로 뽑기: `MT_RENDER_DIR=<폴더> dotnet test tests/Mt.App.Tests --filter EmojiExampleShots`.

## 들어 있는 것

| 무엇 | 어디서 보나 |
|---|---|
| 이모지 22개 | "이모지" 탭 — 고르면 수명 한 번이 돈다 |
| 이모지 리그 `emoji`(자리 › 묶음 › 조각 넷) | "이모지" 탭 아래 리그 칸 |
| 이모지 모션 13개(`emoji_pop`·`emoji_bob`·`emoji_fade`…) — 여러 이모지가 나눠 쓴다 | 모션 목록 |
| 캐릭터 모션 넷(`react_*`) — 이벤트 키 `emoji`·`emoji_off`가 놓여 있다 | 모션 목록 → "모션" 탭의 이벤트 줄 |

## 세 가지 꼴

1. **잠깐 뜨는 것**(머무는 시간이 있다): 느낌물음표 · 반짝별 · 큰땀삐질 · 빠직 …
2. **그림을 넘기는 것**: 난감실타래 · 왁자지껄 · 삐질삐질땀방울 · 말줄임점풍선 — 조각 하나에 장을 여럿 준다(스킨의 그림 넘기기). 말줄임점은 마지막 장에서 멈춘다.
3. **끌 때까지 머무는 것**(`emoji_off`): 플러팅하트 · 곰곰생각구름 · ZZZ · 신나는음표 · 말줄임점풍선 · 행복한벚꽃(조각 셋이 같은 그림 — 자리와 크기는 스킨의 놓임).

반전 판을 보려면 "씬" 탭에서 `s1`의 Scale X를 −1로 둔다 — 말줄임점풍선·쑥스럼풍선이 반대쪽에 반전 판 그림으로 뜬다.

자리는 전부 `faceAura`(구름 둘은 `face`)에서의 오프셋이다 — 캐릭터 초상이 없어 어림값이니 실제 캐릭터에 맞춰 고친다.
